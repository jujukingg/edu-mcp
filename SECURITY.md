# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 1.0.x | :white_check_mark: |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security issue (for example, credential leakage in logs, path traversal in file downloads, or unsafe token storage), please report it privately via [GitHub Security Advisories](https://github.com/jujukingg/edu-mcp/security/advisories/new).

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce or a minimal proof of concept.
- Any suggested remediation if known.

We will acknowledge your report within 72 hours and work with you on a coordinated fix before public disclosure.
